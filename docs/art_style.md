# Art Style Guide – Notebook Sketch

This document defines the visual style used for the **Frozenhunter** event / quest illustrations in Borderland Ponygirls (`assets/img/frozenhunter/`).

## Core Appearance

- **Notebook-sketch look**: Loose, hand-drawn contours with varied line weight.
- Simple, comic-like sketch style with clear shapes.
- Avoid excessive shading, cross-hatching, and ultra-fine linework.
- No gradients, photorealism, or glossy digital painting.
- No written labels inside the illustrations unless deliberately required (e.g. map annotations).

## Technical Specs

| Property              | Value                                      |
|-----------------------|--------------------------------------------|
| Background            | Transparent                                |
| Frame                 | Irregular vignette shape – **no** rectangular sky or hard frame |
| Orientation           | Portrait **2:3**                           |
| Linework              | Black on transparent background            |
| Main black            | `#090a14`                                  |
| Main white            | `#ebede9`                                  |

## Color Palette

- Prefer pure **black & white** whenever possible.
- When additional colors are required, use the **Apollo** palette only:  
  https://lospec.com/palette-list/apollo

## Do / Don’t

**Do**
- Keep shapes readable and bold.
- Vary line weight for energy and focus.
- Use the irregular vignette so the drawing feels like a torn notebook page.

**Don’t**
- Add soft airbrush gradients or glossy highlights.
- Use photorealistic skin / fabric / lighting.
- Draw ultra-fine detail or dense cross-hatching.
- Place text or UI labels inside the illustration (unless the scene specifically needs map annotations).

## Reference

This style is applied to all current Frozenhunter plates (Missing Mare, cargo quests, etc.). Future contributions should follow the same rules so the game stays visually coherent.
